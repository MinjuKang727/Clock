# 시험 및 공부 시간 관리용 아날로그 시계

> 시험 시간 관리, 학습 집중 타이머, 구간 기록을 한 화면에서 처리할 수 있는 단일 HTML 기반 타이머 웹 앱입니다.  
> 별도의 설치나 빌드 과정 없이 브라우저에서 바로 실행할 수 있습니다.

## 주요 기능

### 1. 시험 · 학습 프리셋 및 시간 설정
* **시험 프리셋 제공:** 9급 공무원(110분), 군무원 9급(75분), 수능 국어(80분), 수능 수학(100분), 수능 영어(70분) 프리셋을 지원합니다.
* **집중 모드(`50+10∞`):** 50분 집중과 10분 휴식을 회차별로 자동 반복하며 전환 시 알림을 제공합니다.
* **시작/종료 방식 선택:** 시작 시간(`HH:MM:SS`, 현재 시각 버튼 지원) 기준으로 **총 시험 시간(분·초)** 또는 **정확한 종료 시각(`HH:MM:SS`)**을 설정할 수 있습니다.

### 2. 아날로그 시계 & 멀티 디지털 지표
* **실시간 아날로그 시계:** 캔버스(`760x760`) 기반 시침·분침·초침 렌더링 및 종료 시 시각적 강조를 지원합니다.
* **표시 항목 토글:**
  * 디지털 시계 (`HH:MM:SS`)
  * Count Down (`hh:mm:ss:ms`, 집중 모드에서는 회차별 남은 시간 표시)
  * Count Up (`hh:mm:ss:ms`)
  * 정해진 주기(초·분·시간)마다 반복되는 구간 Count Up

### 3. LED 전광판 & 차임 + TTS 알림
* **LED 전광판:** 대기(`STANDBY`), 진행/알림(`ACTIVE`), 종료(`FINISH`) 상태별 색상/점멸 및 긴 문장 자동 흐르기(Marquee)를 지원합니다.
* **알람 규칙 설정:** `종료 기준 전`, `시작 기준 후`, `정확한 시각` 기준으로 알림을 추가할 수 있으며, `알람 + TTS`, `TTS만 읽기`, `알람음만` 동작을 선택할 수 있습니다.
* **TTS 기본 설정:** 한국어 음성(선히), 말하기 속도(`0.85x` ~ `1.3x`, 기본: 빠르게(`1.3x`)), 음높이: 기본톤(`1.0`) 조절 및 미리듣기 기능을 제공합니다.
* **문구 포맷:** 안내 문구는 `hh:mm:ss | 알림 내용` 형식으로 표시되며, 0시 0분 0초 기준 문구(`종료 시간 입니다.` / `시작 시간 입니다.`)는 중복 없이 출력됩니다.

### 4. 구간 기록(Lap) & 내보내기/불러오기
* **아이콘 및 이름 지정:** 공부(`📖`), 문제풀이(`✍️`), 오답정리(`🔍`), 휴식(`☕`), 식사(`🍱`), 기타(`⏱️`) 아이콘과 구간 이름을 지정해 기록하고, 기록 후에도 아이콘·이름 수정 및 개별 삭제가 가능합니다.
* **자동 저장 및 파일 입출력:** 기록은 `localStorage`에 자동 저장되며, 저장 메뉴에서 **기록 불러오기(`.txt`)**, **텍스트 복사**, **TXT 저장**, **이미지 복사**, **PNG 타임라인 저장**을 지원합니다.
